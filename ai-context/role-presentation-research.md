# Home Specialty Presentation Research

**Status:** Superseded at the user’s direction. The isolated branch now uses editable floating text labels with no specialty SVGs or images; await user review before any merge.

## Observations

The current Home hero uses four same-weight visual tiles. Even after reducing their size, the repeated tile treatment competes with the portrait and reads as a small dashboard rather than a concise statement of expertise.

Review of portfolio inspiration collections and skills-presentation references highlighted three lower-density patterns that fit this portfolio:

1. **Numbered expertise list.** A slim vertical list uses a large two-digit index, small icon, specialty label, and one-line capability. This gives each role hierarchy without requiring four illustrated containers.
2. **Orbit labels.** Four text-first labels sit around the portrait on a light technical orbit, with the associated focus visual appearing only for the active or hovered label. This is expressive but requires an active-state interaction and has more mobile complexity.
3. **Single featured capability panel plus a compact rail.** One selected specialty is shown in a single visual window, while the other three appear as text-first selectable rows. This reduces visual weight and gives the editable focus visuals a purposeful place.

## Recommendation

Recommend **single featured capability panel plus a compact numbered rail**. The panel can use the existing editable focus visual, and all four specialty labels remain editable. Selecting a row changes the featured visual without changing the draft content. It is clearer than four equal cards, preserves existing image/SVG uploads, and collapses naturally into a simple stacked list on mobile.
